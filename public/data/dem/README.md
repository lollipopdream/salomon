# DEMデータについて

このディレクトリには、高尾山周辺のPoC検証に使用する標高タイルを格納します。

- 出典: 国土地理院 地理院タイル(標高タイル)
- URL: `https://cyberjapandata.gsi.go.jp/xyz/dem_png/{z}/{x}/{y}.png`(注: パスは `dem` ではなく `dem_png` が正しい。当初 `dem` で実装したところ全タイルが404となり、リーダーが実際にHTTPリクエストで検証して訂正した)
- 取得日: 2026-08-11(リーダーが `npm run fetch:dem` 実行、対象9タイルすべて取得成功)
- 検証: 取得したタイル(z14/x14529/y6454、中心タイル)をPythonでデコードしたところ、標高範囲は約198m〜583mであり、高尾山頂の公称標高599mと整合する値が得られたことを確認済み(タイル内には山頂ピクセルそのものが含まれていない可能性があるため583mとやや低いが、山域として妥当な範囲)。
- 出典表記の例: 「出典:国土地理院ウェブサイト(地理院タイル)」。production build配信時は`src/scene/attribution.ts`により画面上へ常時表示される。

本データはPoC検証用途に限定して取得したものです。**[2026-08-14 GSI利用条件のresearch-loop再検証]** 当初は「店舗サイネージでの本番運用・外部公開に進む前に、国土地理院への利用条件(オフライン同梱の扱い)の個別確認が必須」としていましたが、2026-08-14の一次情報再検証(`../../../outputs/gsi_dem_license_recheck_final.md`、reviewer score 0.93・fact-checker reliability 0.9)により、`dem_png`は地理院タイル一覧上「基本測量成果以外で出典の記載のみで利用可能なもの」に分類され、個別申請・問い合わせは規約上必須ではないと判断しました。出典・加工表示(上記)は引き続き必要です。国土地理院への確認は禁止されたわけではなく、慎重を期す場合の任意の追加確認(non-blocking)として残しています。

## 取得方法

ネットワークに接続できる開発環境で、リポジトリルートから次を実行します。

```sh
npm run fetch:dem
```

スクリプトは高尾山頂付近（緯度35.6255、経度139.2432）を中心とした半径約1.8km、ズームレベル14のタイルを `public/data/dem/{z}/{x}/{y}.png` に保存します。取得後は、このREADMEの取得日を実際の日付に更新してください。

## ブラウザでの確認

`npm run dev` でアプリを起動し、Chrome DevToolsのNetworkタブでローカルのDEM PNGが取得成功していること、Consoleに読み込みエラーがないことを確認します。Canvas/Image APIを使う読み込み処理はブラウザ専用のため、Node環境のunit test対象外です。
